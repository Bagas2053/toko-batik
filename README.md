# Toko Batik Ananda — Batik Modern Berjiwa Tradisional

Toko online batik dengan branding **Toko Batik Ananda**.

## Branding & UI

- **Nama**: Toko Batik Ananda
- **Tagline**: Batik Modern Berjiwa Tradisional
- **Tema UI**: Teal/toska (#0d4f4f), tembaga/copper (#c47a3a), krem lembut
- **Font**: Playfair Display (judul) + DM Sans (body)
- **Kategori produk**: Kemeja Batik, Dress Batik, Kain Batik

## Struktur

```
toko_batik/
├── backend/          # Node.js + Express + MySQL
├── frontend/         # React + Vite + Bootstrap
└── toko_batik.sql    # Dump database
```

## Cara menjalankan

1. Import `toko_batik.sql` ke MySQL/MariaDB
2. Backend: `cd backend && npm install && npm start` (PORT 5000)
3. Frontend: `cd frontend && npm install && npm run dev`

## Catatan

Kontak, alamat, rekening bank, dan teks konten sudah disesuaikan untuk Toko Batik Ananda.
